# Maker Strategy Pro

Strategic planning and business insights for artists and creative entrepreneurs.

Maker Strategy Pro was designed by:

Alford Wayman of Creek Road Pottery LLC 
917 Creek Road, Laceyville, PA 18623 
www.creekroadpottery.com

Maker Strategy Pro is a comprehensive business intelligence platform designed specifically for artists, craftspeople, and creative entrepreneurs who want to grow their business strategically while staying true to their artistic vision.

### The Problem

Many talented artists struggle with the business side of their craft. They excel at creating beautiful work but find themselves asking:
- "How do I price my work appropriately?"
- "Which events should I prioritize?"
- "What should I make more of, and what should I stop making?"
- "How do I grow my business without losing my creative soul?"

### The Solution

At the heart of Maker Strategy Pro is one fundamental question: **"What change are you trying to make?"**

This isn't just about selling products—it's about understanding your deeper purpose as an artist and how each business decision moves you toward that vision.

## Features

### 🎯 Strategic Event Planning
Plan events with intention, focusing on your change goals rather than just revenue. Define your artistic vision, target customer, and pricing strategy for each event.

### 📊 Business Insights Dashboard
Data-driven recommendations, including:
- Make more/less recommendations based on sell-through rates
- Price point performance analysis
- Seasonal trends and patterns
- Event type ROI analysis

### 📝 Event Reflection Journal
Capture insights and learnings from each event to continuously improve your approach. Track customer feedback, pricing observations, and strategic lessons.

### 📦 Inventory Management
Track your pieces with comprehensive details:
- SKU and categorization system
- Material and finish tracking
- Stock level monitoring
- Price management

### 📈 Performance Analytics
Understand which event types, price points, and strategies work best for your specific goals with detailed metrics and trends.

## Technology Stack

- **Frontend**: Streamlit
- **Backend**: Python 3.8+
- **Database**: SQLite
- **Data Analysis**: Pandas, NumPy
- **Visualization**: Streamlit native charts

## Installation

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Setup

1. Clone the repository:
```bash
git clone https://github.com/yourusername/maker-strategy-pro.git
cd maker-strategy-pro
```

2. Install required dependencies:
```bash
pip install streamlit pandas sqlite3 numpy
```

3. Run the application:
```bash
streamlit run PotteryShop.py
```

4. Open your web browser and navigate to `http://localhost:8501`

## Usage

### Quick Start Guide

1. **Plan Your First Event**
   - Go to "Strategic Event Planning"
   - Answer the key question: "What change are you trying to make?"
   - Fill in event details and creative direction

2. **Add Your Inventory**
   - Go to "Inventory Management"
   - Add your pieces with SKUs, categories, and pricing

3. **Track Event Performance**
   - Go to "Event Management"
   - Record what you brought vs. what you sold
   - Mark events as completed with revenue data

4. **Reflect and Learn**
   - Use "Event Reflection Journal" to capture insights
   - Review "Business Insights" for data-driven recommendations
